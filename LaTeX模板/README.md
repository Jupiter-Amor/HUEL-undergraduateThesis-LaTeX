# 河南财经政法大学本科毕业论文 LaTeX 模板

来源为本工作区 `word版/附件8-2：毕业论文模板（顺序编码制）.doc` 和所附十页截图。原 Word 文件未修改。本目录只提供模板、原封面素材和格式定义，未撰写论文。

## 使用

在本目录运行 `./build.sh`，或执行：

```sh
latexmk -xelatex -interaction=nonstopmode -halt-on-error -outdir=build main.tex
```

入口为 `main.tex`，格式定义为 `huelthesis.sty`。编译结果为 `build/main.pdf`。模板只显示占位内容和固定声明，格式说明与图表、公式示例均在源码注释中，因此空模板的页数与含大段说明的 Word 样张不同。

需要 TeX Live/MiKTeX 中的 XeLaTeX、ctex、fontspec、titlesec、tocloft、natbib、newtxmath、TikZ。使用原版宋体、黑体、仿宋、方正小标宋简体、Times New Roman 和 Arial；本机已用这些字体验证编译。其他机器缺少字体时，复制 `fonts.example.tex` 为 `fonts.tex` 并填写自己的合法字体路径。模板不会静默换用其他字体。

## 供填写论文的 agent 使用

1. 先读 `main.tex` 中相应位置的注释，替换占位文字，保持 `huelthesis.sty` 中已校准的格式。不要把格式说明写入论文，不要为了凑版面插入空段落、缩小字号或虚构内容。
2. 用 `\section`、`\subsection`、`\subsubsection` 表示前三层标题。一级标题连续排版；仅摘要、目录、参考文献和致谢另页。正文与标题后的首段都缩进两字。
3. 采用 `thesisfigure`、`thesistable` 及其交叉引用命令。它们在调用位置插入，图表与题名整体排版；表题在上、图题在下，来源位于表下。源码中的注释示例可以直接启用。
4. 数学使用 `equation`，保持可编辑，自动产生章内编号 `(2.1)`。正文引用用 `\cite` 输出上标方括号序号，参考文献 `\bibitem` 按首次引用顺序放置，采用英文半角标点。
5. 每次填充后重新编译并检查 PDF：字体未替换，文字无溢出，图表及题名没有拆散，目录页码、引用和编号全部更新。

## 原版差异及复刻依据

| 内容 | 本模板处理 |
|---|---|
| Word 磅单位 | 使用 `bp`；纸张11906×16838 twips，左右1418、上下1701 twips |
| 正文1.25倍行距 | 原截图测得实际基线约19.43bp；不是 LaTeX 默认基线再乘1.25 |
| 声明 | 原字体为方正小标宋简体16bp，未额外加粗；正文宋体14bp、基线约27.34bp |
| 目录 | 原说明写小四12bp，但已缓存目录实际约10bp；默认按缓存外观，`\ThesisTOCStricttrue` 切到说明字号 |
| 三级标题 | 原两处示例间距不同；默认2.4bp前后间距，`\ThesisThirdCompactStyle` 使用另一处6bp/单倍样式 |
| 页码 | 保留原版Arial12bp及继承缩进导致的右移24bp；封面无页码，前置页罗马数字，正文从1开始 |
| 图及图题 | 保留原居中段落的继承缩进：图片右移12bp、图题右移24bp |
| 表线 | 原范例含内部竖线、左右无外框；顶底1.5bp，内部0.75bp，不能直接替换为无竖线三线表 |
| 封面素材 | 新增的两幅“原图”逐字节提取自Word，校徽按原裁剪比例显示；已有低分辨率素材保留 |

字体、字号、边距、段距与组件位置依据原文件和截图重建，已进行编译与页面检查。Word 和 TeX 的合成粗体、标点压缩、数学符号度量、英文断词与分页算法不同，不能保证任意新内容逐像素或逐行与 Word 相同；数学符号使用 Times 风格的 newtxmath，拉丁字母、数字和公式编号使用真正的 Times New Roman。
